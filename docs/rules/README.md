# Hackathon reference — NTP Novi Sad / JigJoy, 30–31 October 2026

Everything publicly available about the competition, collected so the team does not have to
re-crawl the site mid-event. Transcribed from `build.jigjoy.ai` and the linked GitHub/docs on
**2026-10-30**. The official pages remain authoritative; where this folder and the site disagree,
the site wins — and note it in `10-source-log.md`.

## The one-line version

Build a system where several agents run **at the same time**, share typed state, and coordinate by
reacting to events — not a fixed sequence of handoffs. Pick one track, submit a public repo with a
README by Saturday 14:00.
